## Updating your existing GitHub Pages site

**Your repository already exists and is already deployed. You do not need to create another one.**

1. Open `https://github.com/Arifssadykov/gomobile-website` and select **Add file → Upload files**.
2. Drag the four files from this ZIP (not the ZIP itself and not the containing folder) into the repository root: `index.html`, `favicon.svg`, `CNAME`, `README.md`.
3. GitHub will indicate that existing files will be **replaced**. Commit the changes directly to branch **main**.
4. GitHub Pages will automatically publish the update. Wait a couple of minutes, then refresh `https://gomobilehq.com` (a hard refresh may help).
5. Keep **Settings → Pages** configured to **Deploy from a branch → main → / (root)** with **Custom domain: gomobilehq.com**. Enable **Enforce HTTPS** once GitHub makes it available.

**You do not need to change any DNS records in Namecheap for this content update.** In particular, do not touch Google Workspace's MX, SPF, DKIM, or TXT verification records.
